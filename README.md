# ios-build

A repository for experimenting with iOS build options, tooling performance, and CI best practices.
Focus is on build infrastructure, not UX development.

## Project Structure

```
ios/
  StarterApp/         - Simple SwiftUI starter app (generated via XcodeGen)
    project.yml       - XcodeGen project spec
    Configurations/   - Debug and Release xcconfig files
    Sources/          - Swift app source files
    Tests/            - Unit tests
scripts/
  ios/                - iOS build and test scripts
  shellcheck/         - Shell script linting and formatting
  swiftformat/        - Swift code formatting
  swiftlint/          - Swift code linting
  xml/                - XML validation and formatting
  utils/              - Shared utilities
.github/
  workflows/
    commit.yml        - Main CI pipeline
  actions/
    xcodebuild-task/  - Reusable composite action for Xcode builds
.githooks/
  pre-commit          - Local pre-commit hook
```

## Prerequisites

Install tools via Homebrew:

```sh
brew install xcodegen swiftlint swiftformat shellcheck xmlstarlet
```

## Local Setup

### Install Git Hooks

```sh
git config core.hooksPath .githooks
```

The hooks handle:
- **pre-commit** — shellcheck, swiftformat, swiftlint on staged files
- **post-checkout** — regenerates Xcode project(s) after branch switches
- **post-merge** — regenerates Xcode project(s) after merges

### Generate Xcode Project

`.xcodeproj` files are **gitignored** — generated by XcodeGen from `project.yml` specs and never committed.
The `post-checkout` and `post-merge` hooks do this automatically once the hooks are installed.
To generate manually:

```sh
bash scripts/ios/xcodegen-generate.sh
```

## Building and Testing

```sh
# Build the app (iOS Simulator, Debug)
bash scripts/ios/xcode-build.sh

# Run unit tests
bash scripts/ios/xcode-test.sh
```

## Code Quality

### SwiftFormat

SwiftFormat handles all Swift code formatting. Configuration is in `.swiftformat`.

```sh
# Validate formatting (all files)
ONLY_TOUCHED_FILES=false bash scripts/swiftformat/validate_swiftformat.sh

# Apply formatting (touched files only)
bash scripts/swiftformat/apply_swiftformat.sh
```

### SwiftLint

SwiftLint handles Swift style and correctness checks. Configuration is in `.swiftlint.yml`.
Formatting rules are disabled in SwiftLint — those are delegated to SwiftFormat.

```sh
# Validate (all files)
ONLY_TOUCHED_FILES=false bash scripts/swiftlint/validate_swiftlint.sh

# Auto-fix (touched files only)
bash scripts/swiftlint/apply_swiftlint.sh
```

### Shell Scripts

```sh
# Validate all shell scripts with shellcheck
bash scripts/shellcheck/validate_shell_scripts.sh

# Format shell scripts with shfmt
bash scripts/shellcheck/apply_shfmt.sh
```

### XML

```sh
# Validate XML files
bash scripts/xml/validate_xml.sh

# Format XML files
bash scripts/xml/format_xml.sh
```

## CI Pipeline

The GitHub Actions workflow (`.github/workflows/commit.yml`) runs the following jobs
in parallel on every PR and push to main:

| Job | Runner | Description |
|-----|--------|-------------|
| `shellcheck` | ubuntu-latest | Validates all `.sh` files with shellcheck |
| `validate-xml` | ubuntu-latest | Validates all `.xml` files with xmlstarlet |
| `swiftformat` | macos-15 | Validates Swift formatting |
| `swiftlint` | macos-15 | Validates Swift style |
| `build-ios` | macos-15 | Builds the app for iOS Simulator |
| `unit-tests` | macos-15 | Runs unit tests (depends on build-ios) |

A reusable composite action (`.github/actions/xcodebuild-task/`) handles
Xcode setup, Homebrew caching, and xcodegen project generation.

## XcodeGen

This project uses [XcodeGen](https://github.com/yonaskolb/XcodeGen) to generate
Xcode project files from YAML specs. Benefits:

- No merge conflicts in `.xcodeproj` files
- Clean, readable project configuration
- Easy to add new targets and schemes

The project spec lives at `ios/StarterApp/project.yml`.

## Configuration

### Build Configurations

- **Debug** (`Configurations/Debug.xcconfig`): No optimization, testability enabled
- **Release** (`Configurations/Release.xcconfig`): Whole-module optimization, DSYM generation

### Deployment Target

iOS 17.0+ (set in `project.yml`)
